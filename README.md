# Bakmie Al-Ridha

Aplikasi Kasir Digital dengan Validasi Porsi Harian dan Laporan Penjualan.

## Struktur Proyek

- frontend: Antarmuka aplikasi kasir.
- backend: API dan logika bisnis.
- supabase: Migrasi dan konfigurasi database.
- docs: Dokumentasi proyek.
